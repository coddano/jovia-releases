# Jovia — versions publiques

Téléchargez la dernière version de Jovia dans l'onglet **Releases**, ouvrez l'image
disque et glissez Jovia dans le dossier Applications (macOS 26 ou plus récent).

Ce dépôt héberge aussi `appcast.xml`, le flux utilisé par Jovia pour se mettre à jour
automatiquement. Il est généré par `scripts/release.sh` dans le dépôt de l'app.
